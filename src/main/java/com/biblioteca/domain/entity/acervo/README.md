# entity/acervo

Hierarquia do acervo.

## Classes

- `ItemAcervo` (abstracta) e as quatro categorias abstractas
- Bibliográficos: `Livro`, `ObraReferencia`, `Periodico` (`RevistaCientifica`, `JornalDiario`, `BoletimInformativo`), `TrabalhoAcademico`, `ObraRaraHistorica`
- Cartográficos: `MapaCarta`, `PartituraMusical`, `Iconografia`
- Multimédia: `MaterialAudio` (`Cd`, `DiscoVinil`, `FitaCassete`, `Audiolivro`), `MaterialVideo` (`Dvd`, `BluRay`, `FitaVhs`, `CdRomEducativo`), `RecursoDigital` (`EBook`, `BaseDadosOnline`, `RepositorioInstitucional`, `SoftwareEducativo`)
- Inclusivos: `LivroBraille`, `MaterialLetraAmpliada`, `MaterialAudioDescricao`, `JogoTabuleiro`, `RecursoApoioEscolar`
